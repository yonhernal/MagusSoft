Android Icon Generator para B4A

Herramienta creada por Jhonn

Descripción

Android Icon Generator es una herramienta diseñada para desarrolladores B4A que necesitan generar iconos adaptativos modernos de forma rápida y automática. Permite seleccionar la carpeta del proyecto, detectar iconos existentes y generar todos los tamaños necesarios para Android.

Características

  • Generación automática de iconos adaptativos (foreground, background, round).
  • Detección del color dominante para el fondo.
  • Compatible con proyectos B4A actuales.
  • Salida organizada en la carpeta /icon.

Configuración en B4A

Main

#AdditionalRes: ../icon

Manifest Editor

SetApplicationAttribute(android:icon, "@mipmap/ic_launcher")
CreateResource(mipmap-anydpi-v26, ic_launcher.xml,
"<adaptive-icon xmlns:android='http://schemas.android.com/apk/res/android'>
    <background android:drawable='@mipmap/background'/>
    <foreground android:drawable='@mipmap/foreground'/>
</adaptive-icon>")
